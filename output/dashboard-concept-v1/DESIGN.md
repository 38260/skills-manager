## 页面结构

1. 保留现有侧栏的导航层级与工作区入口，Dashboard 选中态使用浅绿底。
2. 页头用“Dashboard / 工作台”明确位置，把“扫描导入”和“安装 Skills”收拢到右侧。
3. 三项统计横向排列：技能总量、部署覆盖、已启用 Agent。覆盖用 168 / 192 及细进度条解释，24 项未部署为示例值。
4. 下方为双栏：左侧宽栏呈现近期动态，右侧窄栏呈现各 Agent 的部署数量与项目同步差异。
5. 近期动态保留技能名称、工具、触发来源、结果、项目与时间。未知来源与失败状态分别标示。
6. “让你的 Agent 管理 Skills”变为较矮的引导条，保留“去启用”和关闭入口。实现时继续沿用已有显示条件和用户选择流程。

## 视觉方向

- 延续项目绿色强调，主按钮为深绿色；页面浅灰，内容面板白色。
- 黑灰文字保持清晰对比，细分隔线替代重复嵌套卡片，圆角约 10–12 px。
- 中文采用清晰无衬线字体，英文沿用 Segoe UI 风格，数字与技术标识使用等宽风格。
- 统计、动态和 Agent 列表采用紧凑但可读的间距；界面元素按网格对齐。

## 数据与行为边界

所有数字、项目名称和动态都是绘图示例，不代表当前真实技能库。已启用 Agent 不等于服务在线；部署覆盖不等于无同步差异。

右侧部署概况可复用现有工具列表及技能目标关系；项目差异可复用现有 `sync_health.diverged`。绘图中不增加收入、用户增长或趋势等与本产品无关的指标。

近期动态的“全部 / 技能调用 / 技能更新”属于建议的展示筛选；源码尚未实现。正式重构时需要另行拆分 TODO、验证筛选与详情入口，并执行整体功能测试。
