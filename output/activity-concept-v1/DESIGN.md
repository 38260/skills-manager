# 调用记录重构方案 v1

使用内置 image_gen 工具绘图；完整提示词见 [prompt.txt](prompt.txt)，进度及验收范围见 [TODO.md](TODO.md)。

## 布局

1. 延续 Dashboard 的导航和视觉，页头明确标题“调用记录”，右侧保留扫描更新。
2. 用紧凑横向统计呈现全部记录、明确调用、已确认加载、仅请求／待确认；紧邻统计解释计数口径。
3. 常驻技能搜索、工具及触发方式筛选；更多筛选承载项目、记录类型及开始／结束日期。
4. 日志来源压缩为一行摘要与展开入口；来源异常使用文字及警示符号说明，不只靠颜色。
5. 主区采用记录列表与右侧详情的双栏。记录列表对齐技能／项目、Agent、类型／触发、结果和时间；选中行使用浅绿底和左侧绿线。
6. 右侧展示选中记录的识别依据、记录位置、会话与调用 ID、技能和来源文件路径；保留“在文件夹中显示”“打开技能详情”。
7. 底部保留分页。屏幕中的可见行是单页记录的一部分，不改变现有每页 50 条的设定。

## 示例统计

- 全部记录 1286 = 明确调用 842 + 已确认加载 316 + 仅请求／待确认 128。
- 触发统计 1158 = 手动 492 + 自动 603 + 来源未知 63；只含明确调用与已确认加载。
- 每页 50 条，共 26 页；图中显示第一页与一条选中记录。
- 6 个日志来源启用，1 个需检查，均为示例。

## 行为边界

“已返回”仅表示工具返回，不表示整个任务成功；“来源未知”是触发方式未获明确证据，不等同于“结果未知”。仅请求仍可显示，但不算技能实际使用。

将现有行内展开改为右侧详情是本轮布局提议，尚未实现。扫描运行时仍需要能停止，来源路径和开关仍需停止扫描后才能修改。来源关闭不删除已有历史；新样式不改变这些保护。

图标为生成示意；正式实施继续使用现有 `AgentIcon` 与项目资源，不新增品牌资源依赖。
