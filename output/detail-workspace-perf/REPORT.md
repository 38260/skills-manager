# 技能详情与工作区加载加速报告

日期：2026-10-13

## 原因与修复

1. 技能详情的来源文档在组件打开时就读取。对 Git／skills.sh 来源，这会调用 `Library.source()` 克隆仓库，产生本地正文不需要的网络与磁盘工作。现改为进入“来源与差异”页签才读取；同一版本重复切页复用结果。
2. 全局／项目／关联工作区的正文接口为了查找一个技能，使用了完整扫描结果，连同其他技能的内容指纹与修改时间一起计算。现仍沿用原目录发现和匹配流程，但正文与计数读取跳过同步状态计算。
3. 工作区总览为了显示每个 Agent 的技能数量，原来请求了完整列表。现使用只返回数量的轻量接口；进入单个 Agent 时仍读取完整同步状态。

用户已有的目录哈希缓存、按 ID 查询、启动和刷新节流修改均保留；本次没有整体提交这些修改，也没有修改技能或会话数据。
