## 对比度采样

按浏览器计算后的前景与实际面板底色采样，检查普通文字的 4.5:1 阈值，依据 [W3C 对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)。实现检查也参考 [Web Interface Guidelines](https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md) 的焦点、状态区分和内容溢出要求。

| 采样 | 浅色 | 深色 |
| --- | ---: | ---: |
| 标题 | 17.37:1 | 15.92:1 |
| 说明 | 8.99:1 | 9.13:1 |
| 作者／使用信息 | 6.31:1 | 7.12:1 |
| 选中分类白字／深绿底 | 5.48:1 | 5.48:1 |

这是指定元素的采样结果，不代表所有占位文字、各类标签、全部悬停或全应用无障碍状态均通过。
