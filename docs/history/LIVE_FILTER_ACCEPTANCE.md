# 调用记录 · 实时筛选 / 每页 20 条 / 面板加长验收

交付日期：2026-10-19。隔离库：12 个技能、40 条调用记录，无头 Chrome 实测。

## 改动

1. **输入即筛选**：技能名搜索改为 320ms 防抖实时查询，下拉（工具 / 触发方式 / 类型 / 结果）与日期改动立即生效；回车跳过防抖立刻查。原「查询」按钮删除，`<form>` 一并换成普通容器（避免回车触发整页提交）。「重置」保留，只在存在筛选条件时出现。
2. **每页 20 条**：`pageSize` 30 → 20，40 条记录分 2 页。
3. **面板加长**：压缩页头与统计区占用（页内间距 24 → 12、底部留白 32 → 8、统计卡 `py-3` → `py-2`、数字 22 → 20px、口径说明行高收紧、筛选栏 `py-3` → `py-2.5`），省下的高度全部给下面两块面板。
4. **详情栏加宽**：`xl` 420 → 480、`2xl` 480 → 560（`lg` 保持 380，1280 以下空间不够）。
