# 调用记录「记录详情再拉长」验收

用户反馈：记录详情栏还是太短，「信息量不够」。

## 方案
详情栏不再只与列表同高，改为**跨满整列**：左列自上而下放「统计卡 + 筛选栏 + 记录列表」，右列详情栏从统计卡顶部一直铺到列表底部。
页头保持整宽；<1024（窄屏）回退为单列整页滚动，行为不变。

## 改动
- `src/views/SkillActivity.tsx`：主区由「统计 section + 筛选 div + 两栏 grid」合并为单个 grid
  （`lg:grid-rows-[auto_auto_minmax(0,1fr)]`），统计/筛选/列表各占一列三行，详情栏
  `lg:col-start-2 lg:row-span-3`；其余滚动结构（页签/分页固定、表头吸顶、`.scroll-area` 细滚动条）不变。

## 实测（无头 Chrome + 真实后端，12 技能 / 40 条记录）
| 视口 | 改造前 | 改造后 | 说明 |
| --- | --- | --- | --- |
| 1600×950 | 详情 547，列表 547 | **详情 798，列表 502** | 详情 +251（+46%）；列表 −45（≈1 行） |
| 1600×700 | 详情 297，列表 297 | **详情 548，列表 252** | 详情 +251；列表 −45 |
| 1400×950 | 详情 480 宽档 | **详情 798（宽 480），列表 476** | 同样跨满整列 |
| 1024–1280 | — | 详情 798，列表 382–476，无裁切、无整页滚动 | 左列统计卡不截断（实测 `statLabelClipped:false`） |
| 900×950 | — | 详情排到列表下方，整页滚动（回退正常） | <lg 行为不变 |

取舍：左列变窄后筛选栏换行多占一行（105px，原 50px），列表因此少约 1 行；
换来详情栏 950 高下多显示约 250px 的证据/路径内容。若在意列表行数，可把「更多筛选」收进折叠面板换回单行筛选（后续可选项）。

## 第二轮：左侧记录也拉长（tag: both-long2）
用户反馈「不止详情，左侧记录也要拉长」。总高度固定，从空隙里抠：
- **筛选栏挪回整宽第一行**（`lg:col-span-2`）：放进左列实测缺 108px 必换行（105px 高），整宽后单行 60px，列表拿回 45px。
- **统计卡压紧** `py-2→py-1.5`（62→58px）、**页签/分页栏** `py-2.5→py-1.5`、**页头** `pb-3→pb-2` + 副标题 `leading-4`。
- **记录行密度** `py-2.5→py-2`（57→53px/行），同样高度能多排记录。

实测（1600×950，改造前两项都是 547）：
| 视口 | 详情栏 | 列表滚动区 | 可见行数 |
| --- | --- | --- | --- |
| 1600×950 | 547 → **736** | 547 → **577** | 9 → **10** |
| 1600×700 | 297 → **486** | 297 → **327** | 5 → **6** |
| 1400×950 | → **736**（480 宽档） | → **551** | **10** |
| <1024 | 单列回退不变 | — | — |

验证：`node output/detail-height/verify.mjs both-long2` **22/22 通过**；UI 38/38、Electron 1/1、tsc/ESLint/build 全绿。
附探测脚本 `probe-filter.mjs`（筛选栏换行缺口测量：734 可用 vs 842 需要）。
