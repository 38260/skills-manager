## 用户验收步骤

建议使用一次性测试项目及技能副本。

1. 在项目的启用目录和停用目录放置同名、不同内容的技能。进入项目页面，执行启用；应提示同名冲突，两份正文均保留。停用冲突由自动回归覆盖同样的保护规则。
2. 将一个技能以“复制”模式部署给两个 Agent，编辑其中一个副本。在项目工作区修改对应技能并推送到中央库；应看到中央库完成、无编辑 Agent 同步成功、已编辑 Agent 失败且原因说明原内容已保留。
3. 直接点击“仅重试失败项”；编辑仍存在时应继续拒绝覆盖，独有内容保持不变。妥善合并独有内容并处理冲突后，再次重试，应只更新失败目标。
4. 在全局工作区修改来源副本并上传；同样应保留其他 Agent 的独有编辑，展示逐 Agent 结果。
