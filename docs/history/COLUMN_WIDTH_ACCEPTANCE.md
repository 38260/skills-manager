# 调用记录 / 技能库列表 · 列宽调整验收

交付日期：2026-10-19。数据来自隔离库（12 个技能、40 条调用记录、6 个 Agent）在无头 Chrome 下的实测。

## 改动

- **调用记录**：新增 `≥1800px` 列档，把外层多出来的宽度分给 Agent / 记录类型 / 触发方式 / 结果 / 时间，技能列不再独吞；`≥1536px` 的 Agent 列由 84 加到 104（原先 “WorkBuddy” 被截成 “Workbud...”）。
- **技能库列表**：列表视图容器由 `app-page` 的 1200 放宽到 1440（网格视图仍按 1200 排卡片），名称列 150 → 190（`2xl` 起），右侧状态群 360 → 344、来源修复槽 80 → 64，余量全部给描述列。

## 实测（前后对比）

### 调用记录

| 视口 | 表格宽 | 技能列 前 → 后 | 占比 | Agent 列 前 → 后 |

| 1920 | 1062 | **543 → 443** | **51% → 42%** | 84 → 124 |

### 技能库列表

| 视口 | 行宽 前 → 后 | 名称列 前 → 后 | 描述列 前 → 后 |
| --- | --- | --- | --- |
| 1280 | 1020 → 1020 | 150 → 150 | 148 → 180 |

| 1920 | 1200 → 1440 | 150 → 190 | **98 → 330** |

描述列原先在 1536/1920 下都被压到 98px（一屏全是省略号）；现在 1920 能完整放下一句描述。右侧状态群宽度未溢出（`scrollWidth == clientWidth`）。
